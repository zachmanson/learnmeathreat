<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| URL fragment -> click handler | `location.hash` is written from a build-time-generated id, not from user input |
| Heading text -> sidebar link label | Author-controlled Markdown text interpolated into sidebar markup at build time |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-05 | Tampering | Heading text rendered as outline link labels | mitigate | Rendered via Astro `{expression}` interpolation (auto-escaped); `set:html` must not be used in `RightNavSidebar.astro` |
| T-02.1-06 | Tampering | Click handler writing `location.hash` | mitigate | Handler only ever assigns the `h-N` id read from the clicked link's own `href`, never a value derived from `location` or any other externally-controlled source |
| T-02.1-07 | Denial of service | IntersectionObserver on every heading | accept | Observer count is bounded by heading count in a single static post (single digits); native API, no polling |
</threat_model>
