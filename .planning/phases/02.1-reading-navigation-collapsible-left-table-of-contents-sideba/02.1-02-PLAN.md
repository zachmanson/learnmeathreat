| Browser DOM -> toggle script | Client-side attribute toggling on a static page |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.1-02 | Tampering | Chapter/title strings from frontmatter | mitigate | Values are rendered via Astro's `{expression}` interpolation, which HTML-escapes by default; do not use `set:html` anywhere in `LeftNavSidebar.astro` |
| T-02.1-03 | Information disclosure | Draft posts leaking into the site-wide contents | mitigate | `getCollection('posts', ({ data }) => !data.draft)` predicate is mandatory and asserted in task 2's acceptance criteria |
| T-02.1-04 | Denial of service | Mobile toggle script | accept | Static page, no network calls, no storage writes — worst case is a non-functioning toggle on an already-readable page |
</threat_model>
