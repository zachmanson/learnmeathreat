### `src/lib/rehype-sequential-ids.mjs` (utility, transform)

**Analog:** `astro.config.mjs` lines 1-33 (current `rehypeSlug` usage) + RESEARCH.md's verified read of `node_modules/@astrojs/markdown-remark/dist/rehype-collect-headings.js`'s `visit(tree, (node) => {...})` shape — this is a new file with no direct in-repo analog file, but the *pattern* (a rehype plugin factory returning `(tree) => {...}`) is dictated by how `rehypeKatex`/`rehypeSlug`/`rehypeAutolinkHeadings` already plug into the same array.

**Current pipeline being replaced** (`astro.config.mjs` lines 22-33):
```javascript
processor: unified({
  remarkPlugins: [remarkMath],
  rehypePlugins: [
    rehypeKatex,
    rehypeSlug, // MUST run before autolink-headings - Pitfall 1
    [rehypeAutolinkHeadings, {
      behavior: 'prepend',
      content: h('span.heading-anchor', '#'),
      properties: { class: 'heading-anchor-link' },
    }],
  ],
}),
```

**New plugin to write** (per RESEARCH.md Pattern 1, verified against installed `unist-util-visit` 5.1.0 API):
```javascript
// src/lib/rehype-sequential-ids.mjs
import { visit } from 'unist-util-visit';

const HEADING_TAGS = new Set(['h2', 'h3', 'h4', 'h5', 'h6']); // h1 excluded per D-02

export function rehypeSequentialIds() {
  return (tree) => {
    let counter = 0;
    visit(tree, 'element', (node) => {
      if (!HEADING_TAGS.has(node.tagName)) return;
      counter += 1;
      node.properties = node.properties || {};
      node.properties.id = `h-${counter}`;
    });
  };
}
```

**Ordering constraint (critical, carried from Pitfall 1):** Must stay in the exact array position `rehypeSlug` currently occupies — after `rehypeKatex`, before `rehypeAutolinkHeadings`. Astro's internal `rehypeHeadingIds` (unconfigurable, appended last) only writes an id if one isn't already a string, so placement before `rehypeAutolinkHeadings` is what makes both the DOM `id` and Astro's own `render(post).headings` array agree.

<script is:inline>
  const headingEls = [...document.querySelectorAll('article :is(h2, h3)[id]')];
  const sidebarLinks = new Map(
    [...document.querySelectorAll('.right-nav a[href^="#"]')]
      .map((a) => [a.getAttribute('href').slice(1), a])

  const observer = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
