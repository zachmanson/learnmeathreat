<objective>
Replace the text-derived heading-slug scheme (`rehype-slug`) with a position-based sequential id scheme (`#h-1`, `#h-2`, ...) across the whole Markdown pipeline, per D-01 and D-02.

Purpose: Shared links to a section survive later rewording of that heading. This also becomes the single source of truth for both sidebars in plans 02 and 03 — Astro's internal `rehypeHeadingIds` preserves ids that already exist, so `render(post).headings[].slug` will automatically carry the same `h-N` values as the DOM.
Output: `src/lib/rehype-sequential-ids.mjs`, an updated `astro.config.mjs` pipeline, `unist-util-visit` as an explicit dependency, and updated pipeline tests that lock the new scheme.
</objective>
