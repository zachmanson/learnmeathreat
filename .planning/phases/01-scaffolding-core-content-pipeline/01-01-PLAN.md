Content collection contract (src/content.config.ts) — the single source of truth for post data:

```typescript
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

const posts = defineCollection({
  loader: glob({ pattern: '**/*.md', base: './src/content/posts' }),
  schema: z.object({
    title: z.string(),
    date: z.coerce.date(),             // REQUIRED coercion - RESEARCH Pitfall 4
    tags: z.array(z.string()),         // freeform strings, NOT z.enum - D-04
    excerpt: z.string(),
    slug: z.string(),                  // explicit URL source of truth - D-05
    draft: z.boolean().default(false), // D-03
  }),
});

export const collections = { posts };
```

Post route contract (src/pages/posts/[slug].astro):

```astro
---
import { getCollection, render } from 'astro:content';
export async function getStaticPaths() {
  const posts = await getCollection('posts', ({ data }) => !data.draft);
  return posts.map((post) => ({ params: { slug: post.data.slug }, props: { post } }));
}
const { post } = Astro.props;
const { Content, headings } = await render(post);
---
```

Layout contract (src/layouts/Layout.astro): accepts a `title: string` prop, renders `<html lang="en">`, a `<head>` containing `<title>`, a header with site title plus Home/About nav, and `<main><slot /></main>`. Every page in this project renders through it.
