    Behavior, all in one `visit(tree, callback)` pass that early-returns for any node whose `type` is neither `containerDirective` nor `leafDirective`:

    1. Callouts and definitions (D-09/D-10/D-11/D-12, CONT-09/CONT-10): for directive `name` in the set `note`, `warning`, `tip`, `definition`, set `node.data.hName = 'div'` and `node.data.hProperties = { class: 'callout callout-' + node.name }` (build the properties object via `h('div', { class: ... })` so hastscript normalizes the class value, matching the official remark-directive README pattern). Children are left untouched so nested Markdown — bold, links, inline `$math$`, multiple paragraphs — still renders. Accept both `containerDirective` and `leafDirective` node types for these names.

    2. Figures (D-01/D-02/D-03, CONT-06): for `name === 'figure'` on a `leafDirective`, increment a per-file `figureCounter`, read `src` and `alt` from `node.attributes` (default `alt` to the empty string), compute `isSvg` from a case-insensitive `\.svg$` test on `src`, set `node.data.hName = 'figure'` and `node.data.hProperties = { class: 'content-figure' }`, then replace `node.children` with exactly two synthetic nodes: an `img` element carrying `src`, `alt`, `loading: 'lazy'`, and `class: 'invertible'` only when `isSvg` is true (omit the class entirely for raster — do not emit `class=""`); and a `figcaption` element whose children are a text node `Figure ${figureCounter}: ` followed by the directive's original children (the bracketed label), so caption text keeps its inline Markdown.

    Do not wire it into the config in this task; Task 3 does that.
