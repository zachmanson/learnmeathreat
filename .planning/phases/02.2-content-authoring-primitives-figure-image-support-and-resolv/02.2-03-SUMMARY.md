# Phase 02.2 Plan 03: Citations and Bibliography (CONT-08) Summary

**Wired rehype-citation with a `\cite{key}` -> `[@key]` translation plugin backed by a project-root `references.bib`, verified via real build output (not assumption) that the auto-inserted bibliography has no heading and never touches the on-this-page outline sidebar, and locked the whole contract down with 5 new tests.**

## Performance

- **Duration:** ~45 min
- **Tasks:** 3 completed
- **Files modified:** 8 (2 created: references.bib, remark-cite-translate.mjs; 6 modified: package.json, package-lock.json, astro.config.mjs, authoring-primitives.md, prose.css, authoring-primitives.test.mjs)

## Accomplishments

- Installed `rehype-citation@2.3.2` with no top-level `citation-js` dependency (`npm ls citation-js` returns empty)
- Created `references.bib` at the project root with three real BibTeX entries: `shor1997` (Shor's 1997 factoring paper), `grover1996` (Grover's 1996 search paper), `nakamoto2008` (Bitcoin whitepaper)
- Wrote `src/lib/remark-cite-translate.mjs`: a named `remarkCiteTranslate` factory that rewrites `\cite{key}` text to `[@key]` in mdast `text` nodes only, deliberately leaving `\cite{}` inside inline code/code blocks untranslated (mirrors `remark-math`'s code-span exemption)
- Wired both into `astro.config.mjs`: `remarkCiteTranslate` first in `remarkPlugins`; `[rehypeCitation, {...}]` inserted between `rehypeKatex` and `rehypeSequentialIds` in `rehypePlugins`
- **Resolved RESEARCH.md's two flagged LOW-confidence open items empirically**, by temporarily adding `\cite{shor1997}` to the published seed post, running a real `npm run build`, reading the emitted `dist/posts/why-quantum-computers-threaten-bitcoin/index.html`, then reverting the edit (confirmed `git diff --stat` empty afterward):
  - **Assumption A2** (bibliography path resolution): `path: process.cwd()` worked correctly on the first attempt - the build succeeded and `references.bib` resolved without needing a fallback.
  - **Assumption A3 / Open Question 1** (exact emitted markup, heading interaction): rehype-citation emits `<div id="refs" class="references csl-bib-body"><div class="csl-entry" id="bib-KEY">...</div>...</div>` — **no heading element at all**. Because there's no heading, it never receives a `rehypeSequentialIds` `#h-N` id and never appears in the `outlineHeadings` filter in `[slug].astro`. Verified directly in the rendered `<aside class="right-nav">` output: only the post's real `h2`s appeared, no bibliography entry.
- Added citations to the fixture post `authoring-primitives.md`: two distinct keys (`shor1997`, `grover1996`), a repeated `shor1997` citation (dedup control), a deliberately-untranslated `` `\cite{shor1997}` `` inside inline code, and left `nakamoto2008` uncited as the D-08 negative control
- Styled the citation output in `prose.css` under a `/* --- Citations and references (CONT-08) --- */` section, targeting the actual observed `#refs`/`.csl-entry` selectors (not a guessed one), using only `--text`, `--muted`, `--accent`, and the `--space-*` scale — zero hex/rgb literals in the new section, zero new `.prose` selectors
- Made no change to `[slug].astro` — justified above, since the bibliography has no heading to exclude
- Appended tests 9-13 to `tests/authoring-primitives.test.mjs`: untranslated-outside-code absence, untranslated-inside-code presence, cited-surname presence, uncited-control-surname absence (D-08), single-entry deduplication for the repeated key
- Manually verified the D-08 negative-control test is non-vacuous: temporarily cited `nakamoto2008` in the fixture post, rebuilt, re-ran `node --test tests/authoring-primitives.test.mjs`, confirmed test 12 failed with the expected assertion message, then reverted (confirmed `git diff --stat src/content/posts/` empty)
- Full suite green: 66/66 (61 pre-existing + 5 new; authoring-primitives.test.mjs alone now has 13 tests)
