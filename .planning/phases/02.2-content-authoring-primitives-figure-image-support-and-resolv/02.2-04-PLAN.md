<task type="checkpoint:human-verify" gate="blocking">
  <what-built>
    Phase 02.2 added four Markdown authoring primitives to the build pipeline, all rendered at build time with zero new client JavaScript:
    - Figures: `::figure[caption]{src alt}` renders an image with an auto-numbered "Figure N" caption that restarts at 1 each post. SVG figures get a dark-mode invert filter so black-line-on-transparent diagrams become white-line-on-dark; PNG/JPG figures are deliberately never inverted.
    - Citations: `\cite{key}` resolves against the project-root `references.bib` and renders a formatted mark plus an auto-generated References section listing only the entries that post actually cites.
    - Callouts: `:::note`, `:::warning`, `:::tip`, each explicitly closed by a bare `:::`.
    - Definitions: `:::definition`, same explicit close.
    The DSGN-01 "no marketing imagery" guard test was rewritten (not deleted) so it still fails on hero/stock images and CSS `background-image`, while permitting authored content figures inside post body content.
    All styling reuses the existing five colour tokens only — no new colours were introduced.
  </what-built>
  <how-to-verify>
    Open the preview URL reported in Task 1 and go to `/posts/authoring-primitives/`. Then:

    1. **Figures, light mode.** Confirm two figures appear, captioned "Figure 1: ..." and "Figure 2: ..." in that order, and that captions read as captions (smaller, muted, centered) rather than as body text.
    2. **SVG dark-mode invert.** Toggle to dark mode. The vector diagram (Figure 1) should flip to light lines on the dark background and stay legible. Flag it if it looks washed out, ghosted, or like a rendering bug rather than a deliberate diagram.
    3. **Raster is NOT inverted.** In dark mode, confirm the PNG (Figure 2) still shows its original colours — this is the deliberate difference from Figure 1. Toggle back and forth once to confirm it does not change.
    4. **Callouts.** Find the note, warning, and tip blocks. Confirm each is a distinct bordered box, that you can tell them apart at a glance without reading the label, and that they still feel minimal and text-first rather than like a docs-site widget. Check both light and dark mode.
    5. **Definition block.** Confirm the definition box reads as clearly different from the three callouts (it uses a thicker accent border) and that a term-plus-explanation inside it reads naturally.
    6. **Citations and References.** Find the inline citation marks in the body text — confirm they read as citations and not as stray brackets. Scroll to the bottom and confirm the References section lists only the sources this post cites, formatted like a reference list. If the citation marks are clickable, confirm one jumps to its entry.

    8. **Mobile.** Narrow the browser to roughly 375px wide (or use device emulation). Confirm figures scale down without overflowing, callouts and the definition box do not push a horizontal scrollbar, and the References entries wrap cleanly.
    9. **Whole-page sanity.** Confirm the existing post at `/posts/why-quantum-computers-threaten-bitcoin/` is unchanged — same math, code blocks, heading anchors, and sidebars as before this phase.
